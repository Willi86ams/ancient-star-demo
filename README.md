# 梨园初梦 · 16:9 场景行走小样

直接用浏览器打开 `index.html` 即可，无需安装、联网或账号。请保留同目录的 `game.js`、`scene.js`、`scene.css` 和 `assets` 文件夹。进度在浏览器本地保存；重开保留命簿。

## 场景操作

- WASD / 方向键：自由走动，斜向移动速度保持一致。
- E：靠近旧宅、练功亭、茶楼、布庄、戏台后展开交互。
- 点击场景中的地点标签：自动走近并交互；手动移动会中止自动行走。
- Esc：收起对话或衣箱；打开模态窗口、衣箱或切换到其他页面时暂停移动。
- 右上“衣箱”：换装；“?”：玩法、序幕和重开；“命簿”：结局图鉴。
- 右下：领取今日功课赏钱、歇息推进日期、打开手记。
- 窄屏提供触屏方向按钮，横屏体验更佳。场景始终保持 16:9。

走动不消耗行动。脚下的庭院边界阻止角色走入建筑和画外；坐标随进度保存。

## 可玩内容

- 一张 AI 生成的戏班庭院背景，集成状态、任务、对话和地点按钮，角色支持行走与换装。
- 三天日程、行动点、才艺、盘缠、每日练习奖励。
- 茶楼帮工与剧情线索，三套可切换服饰，其中戏服需购买。
- 方向键或触屏节奏练习，8 拍，可中止并返还行动。
- 《空台夜唱》谜题、三个失败结局、普通结局与隐藏结局。
- 本地存档、跨局结局图鉴、可重看的开场故事。

此小样的节奏练习是唱跳玩法的占位演示，未接入录音、AI 唱歌评分、摄像头体感或在线模型。音效为浏览器合成的提示音，未使用真实戏曲录音。参考截图仅用于界面构图，未直接复制其人物或场景。

## 一条通关路线

第一日：茶楼帮工两次，练习身段一次，打听旧戏一次，领取 15 文功课赏钱。

第二日：练习一次，领取 15 文，购买朱砂戏服，帮工一次，剩余两点行动进入古戏台。

这时有 140 文、3 级才艺、戏服与线索。选择“沈阿蘅”抵达隐藏结局，选择“故人”抵达普通结局。

## 制作方向

配色：深青绿界面、旧金描边、朱砂戏服、暖色暮光。视觉中心是一张 16:9 原创庭院画面；地点按钮与 NPC 位于场景中，对话在画面下方展开，任务与衣箱可收起。

背景由内置 image_gen 工具生成，保存在 `assets/opera-courtyard.png`；完整提示词见 `assets/scene-prompt.txt`。角色为可换色 SVG，固定步长移动逻辑位于 `scene.js`，原有养成逻辑位于 `game.js`。

第一版界面备份为 `index-v1.html`。`scene-shell.html` 是新版界面源模板；调整角色素材后可运行 `node build-scene.cjs` 重建 `index.html`。直接试玩无需执行构建。

## 本地预览

也可以在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后访问 http://127.0.0.1:8765 。

自动检查：在上级工作区已有 Playwright 的环境中执行 `node ancient-star-demo/verify.cjs`。检查涵盖行走、交互、边界、模态暂停、位置存档，以及五个结局与原有节奏玩法。
